# Simplify Aptify

This library is developer by Christopher Hunter. It contains just a bunch of Aptify things to share with the community.

## No PerByte.Rexies

The PerByte.Rexies library should be a choice for clients. While I support and suggest it, you might not want all of it. 
As well I wanted examples of how to do some of the things Rexies does but I didn't want all of it.
